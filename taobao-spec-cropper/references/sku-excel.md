# SKU Excel

## 输入与范围

- `--root` 指向包含商品子文件夹的项目目录。仅处理其中有 `商品信息.json` 的直接子文件夹；支持重复传入 `--exclude '商品文件夹名'`。只处理单款时可传 `--product-dir`。
- 每款需有一个 `规格图` 或名称包含 `规格图_800_PNG` 的目录；也可用 `--spec-dir-name` 明确指定。编号与颜色来自该目录直接包含的 `01_颜色.png`，按数字排序；编号必须从 1 连续且不重复。多个版本目录时先确定本次使用哪一份，不混合旧图。
- JSON 用 UTF-8，支持 BOM。读取 `price` 数值或数字字符串；空值、缺失、非有限值与负价报错，不猜价。
- `--template` 指向用户提供的模板。必须为 XLSX 内容；兼容内部是 XLSX 的 `.xls` 文件，真正的旧版 XLS 需先另存为 XLSX。模板未提供时先定位项目里的 SKU 模板，找不到再询问。
- 优先填充 `AI批量上传` 工作表，否则填充活动工作表；首行 A:C 必须是“颜色分类、价格、数量”。从第二行替换模板示例数据，其他工作表及隐藏状态保留。

## 输出与检查

每张图生成一行：`01#白色 (半米价)`、JSON 原价格、`100`。价格与数量为数值单元格，小数价格保留；不根据 JSON 的“元/米”描述自动换算。颜色名沿用已检查的规格图文件名（必须是 `01_白色.png` 这种颜色命名，不允许 `No.01` 编号名），仍属于视觉描述。

**默认输出到规格图目录内的 `sku.xls`**，不打包 ZIP；文件内容仍按模板工作簿（XLSX）保存。要输出到商品文件夹并改用其他文件名时，传 `--output-in-product-dir --output-name '<商品文件夹>_SKU.xlsx'`。写入前检查整批输入和同名输出；失败时修正指出的问题再重跑，不能直接覆盖用户旧表。写入时仍可能因文件占用等系统原因部分完成，应检查实际输出后只继续未完成商品。

脚本使用 `openpyxl` 复制并填充模板，运行后重新读取数据核对。交付前确认行数与规格图一一对应、价格等于 JSON、数量均为 100、编号和颜色一致、隐藏工作表仍隐藏；查看实际工作表，确认长颜色名和数字不被截断。

```powershell
python scripts/generate_sku_excel.py --root '项目目录' --template '项目目录/SKU模板.xls' --sku-excel --exclude '不处理的商品'
python scripts/test_generate_sku_excel.py
```

不传 `--sku-excel` 不生成任何文件。这个参数属于 SKU 脚本，不是 `crop_specs.py` 的参数。注意：默认输出的 `sku.xls` 是 XLSX 内容，用 openpyxl 直接按路径读取会因 `.xls` 扩展名报错，需以文件对象/字节流方式打开核对。
