# 本次裁切配置

由执行技能的助手针对每张新图建立配置。JSON 使用 UTF-8。所有 `box` 均为 **EXIF 转正后的原图像素坐标** `[left, top, right, bottom]`，右/下边界不包含在内。配置里的 `source_size` 必须与实际尺寸吻合。

## 规则网格

下面只是一个“第一行两项、第二行一项”的示例，不能直接套到其他图片。

```json
{
  "source_size": [600, 500],
  "grid": {
    "x_edges": [0, 300, 600],
    "y_edges": [30, 250, 470],
    "row_counts": [2, 1]
  },
  "items": [
    {"color": "白色"},
    {"color": "浅蓝色"},
    {"color": "黑色"}
  ]
}
```

- `x_edges`、`y_edges` 是实际网格边界，允许不等距；裁掉页头页尾。`row_counts` 可省略，省略表示每行满列；不可为不足一行的末格生成假图片。
- 网格模式按行优先展开，`items` 数量必须与有效格数一致。中间有空位、错列、跨列或每行列宽不同，直接用逐项 `box`。
- 每项可以用 `box` 覆盖网格的框位。`color` 必须是非空字符串，脚本不会擅自猜颜色。文件名序号是输出顺序，数字图像仍保持原样。

## 逐项定位与纠正编号

```json
{
  "source_size": [900, 650],
  "items": [
    {
      "color": "白色",
      "box": [30, 40, 350, 270],
      "number_box": [172, 220, 201, 244],
      "trim": false
    },
    {
      "color": "深蓝色",
      "box": [410, 42, 735, 275],
      "number_region": [495, 218, 650, 264]
    }
  ]
}
```

- `box`：完整布片及其编号/自带颜色文字所在的小格，不含邻项。
- `number_box`：只围住原始数字的一小块区域，可以有少量白边。脚本按其中真实暗像素重新求紧包围框。它优先于 `number_region`，不可包含下一行颜色名或布片。检测不到墨迹会报错，不会捏造锚点。
- `number_region`：候选编号区域，允许数字下还有文字；自动选择第一条合适的暗字行。省略时尝试小格下部、横向中间区域。该算法不认识数字的含义，必须看 `source-boxes.png` 核实。
- `trim`：默认 `true`，去除小格的外围近白留白并保留少量安全边距，不移除内部背景。淡色边界不可靠或裁框已精确时设为 `false`。
- 没有编号：在单项设置 `"alignment": "content"`；不要为其填写虚构 `number_box`。若全部无编号，可在 `options` 中统一指定。

## 可选的整批布局参数

```json
{
  "options": {
    "alignment": "number",
    "content_width": 660,
    "number_center_x": 400,
    "number_bottom": 590,
    "margin": 32,
    "ink_threshold": 160,
    "background_threshold": 248
  }
}
```

把 `options` 合并到配置根对象，不是另一个单独配置文件。默认值即上面所示。

- `content_width` 是整批最宽内容的目标宽度。脚本使用共同倍率；若某项不能完整放下，会统一缩小整批，确保内容不被画布截断。
- `number_center_x`、`number_bottom` 是编号统一位置；不得逐张修改目标来掩盖误检测。`margin` 为安全边距。
- `ink_threshold` 是判断暗字的 RGB 上限；近白背景裁边阈值由 `background_threshold` 控制。修改阈值后重新看预览。
- 单图示例：一个 `items`，框住主体，`alignment: content`。透明背景会合成到白底，输出始终为 RGB PNG。

## 预览和结果

`preview` 输出原图框位图、800×800 模拟成品的缩略联系表、`report.json`；不生成交付 ZIP。框位图中红框为小格、蓝框为实际保留内容、绿框为编号，旁边的红色序号对应输出序号。

`render` 输出每项 PNG，校验后在 `_qa/` 保存框位图、联系表、`report.json`，并在输出目录旁生成只含成品 PNG 的 ZIP。报告包含源坐标、实际输出编号包围框、共享缩放倍率、放大提示和校验结果。预览与成品目录都必须尚不存在，重新运行请选新目录。
